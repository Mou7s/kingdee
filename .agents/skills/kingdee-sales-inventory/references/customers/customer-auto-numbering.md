# 客户自动编码与流水号校准

适用于本账套账套 `BD_CUSTOMER` 的 `CTK + 6位流水号`。

## 规则明细

- 常量：`CTK`，长度 `3`。
- 流水号：长度 `6`，步长 `1`，补位符 `0`。
- 不勾选“右侧填充”，使数字在左侧补零：`7` → `000007`。
- 勾选“默认规则”。
- “允许修改”关闭；“手动补号”关闭。
- 若要求只取最大号之后的号码，“自动补号”关闭；它不是自动编号，而是断号回填/重用机制。
- 要求永远保持六位时勾选“禁止自动升位”。

## 已有数据之后如何设下一号

规则明细的“起始值”是规则定义值，不能替代当前流水号状态校准。先实时查询 `BD_CUSTOMER` 的最大目标编码，再在界面：

1. 点击“查询流水号”，记录当前流水位置。
2. 点击“更新流水号”。
3. 若弹窗字段表示“当前值/已使用最大值”，填最大已用流水号；若字段表示“下一流水号/下一个值”，填下一号。
4. 保存后再次“查询流水号”确认下一号。

例如现有最大编码为 `CTK001006`：

- 当前值/已使用最大值 = `1006`；或
- 下一流水号 = `1007`；
- 下一张新客户应自动显示 `CTK001007`。

再新建一张真实客户验证下一张为 `CTK001008`，不要为了测试创建无用客户。若流水号按组织分别维护，要确认当前客户使用组织和“查看适用组织”范围。

## 重要边界

自动流水号通常保证递增和唯一，不保证绝对无断号。取消、保存失败、删除草稿、并发建档等情况可能消耗号码；不要为追求连续号码而回填已使用或已产生业务关联的编码。

依据：金蝶云产品手册“编码规则”对“允许修改、起始值、步长、补位符、右侧填充、编码依据”的字段说明；本账套账套现场截图中的“查询流水号/更新流水号”操作入口。
