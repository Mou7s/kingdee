# 物料分类核对参考

## 目的

新建料号前，先用账套中现有物料建立“相似物料证据”，再分别确定：

1. **物料分组**：按用途、使用部门和业务管理方式选择，例如办公用品、厂务、电工材料。
2. **存货类别**：单独核对 `MaterialBase[].CategoryID`，不能把物料分组编码当成存货类别编码。
3. **单位与规格**：优先采用同用途、同计量方式的当前有效物料；没有规格时规格字段留空，报文可用单个空格兼容空值校验。
4. **料号**：精确查重后，按目标分组的现有编码段和最大流水号提出候选编码。

## 推荐调查顺序

### 1. 查询相似名称

使用 `BD_MATERIAL` 查询名称、品牌、功能相关关键词，并带出：

```text
FNumber,FName,FSpecification,FDocumentStatus,FForbidStatus,
FMaterialGroup.FNumber,FMaterialGroup.FName,FBaseUnitId.FName
```

只把 `FDocumentStatus=C` 且 `FForbidStatus=A` 的物料作为主要参考。已禁用物料只能作为历史线索，不能直接照抄。

注意：K3 查询过滤条件中的 `LIKE` 通配符必须保留 SQL 单引号，例如：

```text
FName like '%水龙头%'
```

在 Windows Git Bash 的 `bun -e` 单引号脚本中，避免让 shell 吞掉过滤条件的单引号；可在 JavaScript 中构造 `\u0027`，或改用临时脚本文件。

### 2. 用 View 核对真实存储值

对最接近的 1–3 个有效物料调用：

```js
await api.post("DynamicFormService.View", {
  formid: "BD_MATERIAL",
  data: { Number: materialNumber },
});
```

从返回结构读取：

- `MaterialGroup.Number` / `MaterialGroup.Name`
- `MaterialBase[0].CategoryID.Number` / `MaterialBase[0].CategoryID.Name`
- `MaterialBase[0].BaseUnitId`
- `MaterialStock[0].StoreUnitID`
- `MaterialBase[0].ErpClsID`

`FMaterialBase` 不是 `ExecuteBillQuery` 中可直接使用的级联字段；若查询报“元数据中标识为 FMaterialBase 的字段不存在”，改用简单查询字段，再通过 `View` 取 `MaterialBase` 的真实值。

## 已核对案例：联塑胶水龙头

在主账套组织账套中调查“联塑胶水龙头”时得到以下证据：

| 现有物料 | 状态 | 物料分组 | 存货类别 | 备注 |
|---|---|---|---|---|
| `N409000026` 联塑冲水箱 | 有效 | `409 杂项/厂务` | `CHLB08_SYS 办公材料` | 最接近的同品牌厂务水路物料 |
| `N409000087` 水箱配件 | 有效 | `409 杂项/厂务` | `CHLB08_SYS 办公材料` | 同用途厂务配件 |
| `N406000165` 110排水管（联塑） | 有效 | `406 电工材料` | `CHLB08_SYS 办公材料` | 管材/管件类的另一候选分组 |
| `N406000083` 大胶水 | 有效 | `406 电工材料` | `CHLB08_SYS 办公材料` | 电工用胶水，不能单独决定水龙头分类 |
| `406000026` 水龙头 | 已禁用 | `406 电工材料` | `CHLB13_SYS 维修费` | 历史线索，不应直接复制 |
| `N401000204` 不锈钢水龙头 | 有效 | `401 办公用品` | `CHLB08_SYS 办公材料` | 办公区域用品候选，不如厂务用途匹配 |

若该物料用于厂务水路维修，推荐 `409 杂项/厂务`；若现场明确按水管、阀门、管件统一归电工材料，再选择 `406 电工材料`。这类分组存在合理歧义时，必须把用途判断交给用户确认。

当时账套中：

- `N409000096` 为 409 编码段当前最大值；`N409000097` 只是基于流水号的候选值，不是自动授权的最终编码。
- 精确查询没有发现名称“联塑胶水龙头”的现有物料。
- 无规格时建议规格型号留空；数量单位按同类水路配件通常建议“个”，仍应以实际采购计量为准。

## 已核对的跨用途分类案例

这些案例用于建立检索方向，不替代每次建料前的当前账套查询；同名物料仍要结合实际使用部门和用途确认。

| 使用场景/物料特征 | 优先检索的物料分组 | 常见存货类别 | 账套证据方向 |
|---|---|---|---|
| 测试分选机用传感器（如带 FU 型号） | `30108 测试分选` | `CHLB10_SYS 设备配件` | 现有 `传感器`、光电/接近传感器集中在 30108 或对应设备部门分组 |
| 模压设备用托盘臂、连接块、连接杆 | `30105 模压` | `CHLB10_SYS 设备配件` | 现有模压连接件和按钮/阀类配件可作为同用途参照 |
| 生产现场电子秤 | `30109 其他` | `CHLB10_SYS 设备配件` | 现有 15kg、150kg 电子称在 30109；不要因“称”字面归到五金或厂务 |
| 厂务水路的联塑水龙头、角阀、冲水箱配件 | `409 杂项/厂务` | 常见为 `CHLB08_SYS 办公材料` | 联塑冲水箱、水箱配件及本次同批厂务水路物料在 409 |
| 通用给排水管、直通、弯头、三通、球阀、电工水路耗材 | `406 电工材料` | 常见为 `CHLB08_SYS 办公材料` | 账套大量不同口径管件、阀门集中在 406；若明确是厂务维修用途，需与 409 备选比较 |
| 开孔器 | 需按用途在 `409`、`406` 或 `40501` 中核对 | 常见为 `CHLB08_SYS 办公材料` | 账套中 110/160 开孔器在 409，玻璃开孔器在 406，四分开孔器在 40501，不能只按名称固定分类 |

### 供应商来源的边界

用户说“某五金店送来的”时，供应商来源可以作为记录和查找线索（例如先核对供应商编码），但不能单独决定物料分组；除非用户明确要求并已核对字段，否则不要把来源写进物料名称，也不要擅自设置默认供应商。

## 输出模板

向用户汇报时分开写：

- **已验证事实**：列出查询到的相似有效物料及真实分组/存货类别。
- **建议值**：名称、规格、分组、存货类别、单位、候选料号。
- **不确定项**：用途导致的备选分组、单位或税率差异。
- **下一步**：用户确认候选值后，先 dry-run，再按明确授权执行 Save → Submit → Audit，并回查新料状态。
