# 物料辅助属性（Flex Aux Property）排查

## 结论（2026-08-31 实测，N102020002 案例）
- 物料 N102020002（SBD20510P86D01ALH-L，(蓝膜片)2.185*2.185）在 T_BD_MATERIAL FMATERIALID=867383，分组 FMATERIALGROUP=117745（FNUMBER=10202），创建人 管理员A 2026-07-22。
- 同分组 10202 全部 375 物料各有 8 行 T_BD_MATERIALAUXPTY，N102020002 与老料 102020441 启用一致：仅 FF100024 芯片数量/划片要求=1、FF100026 芯片尺寸/晶圆尺寸=1，其余 6 个为 0。
- 生产补料单因未填这两个维度报“提交:辅助属性…芯片尺寸/晶圆尺寸和芯片…”失败，属于分组标配校验，非单张建错。

## 表结构
- T_BD_MATERIALAUXPTY(FENTRYID, FMATERIALID, FAUXPROPERTYID, FISENABLE, FISCOMCONTROL, FISMUSTINPUT, FISAFFECTPRICE/PLAN/COST, FVALUETYPE, FVALUESET, FUSEORGID) — 1物料×8属性
- T_BD_FLEXAUXPROPERTY(FID, FFLEXNUMBER e.g. FF100024/FF100026/FF100017, FFORMID=BD_FLEXAUXPROPERTY) + T_BD_FLEXAUXPROPERTY_L(FID, FLOCALEID=2052, FNAME)
- T_BD_MATERIAL(FMATERIALID, FNUMBER, FMATERIALGROUP) 名称/规格在 T_BD_MATERIAL_L
- 值池（每个物料在某属性下有哪些可选值）：`T_BD_AUXPTYVALUE(FAUXPTYVALUEID, FMATERIALID, FMATERIALAUXPROPERTYID=属性FID, FFORMID='BD_AuxPtyValue', FOPERATIONSTATUS, FFORBIDSTATUS)` → 值条目 `T_BD_AUXPTYVALUEENTITY(FENTRYID, FAUXPTYVALUEID, FAUXPTYID, FAUXPTYNUMBER, FISDEFAULT, FISDISABLE)` → 显示名 `T_BD_AUXPTYVALUEENTITY_L(FPKID, FENTRYID, FLOCALEID=2052, FAUXPTYNAME)`；单据侧引用的值编码走 `T_BAS_FLEXVALUESENTRY(FNUMBER)`。
- 本账套 8 个属性 FID 对照：`100017 印字`、`100018 档位/背材`、`100021 厂商型号`、`100024 芯片数量/划片要求`、`100025 供应商`、`100026 芯片尺寸/晶圆尺寸`、`100027 包装要求`、`100029 供应商简称`。

## 常用查询

```sql
-- 单料全部辅助属性
SELECT a.FAUXPROPERTYID,f.FFLEXNUMBER,l.FNAME,a.FISENABLE,a.FISMUSTINPUT
FROM T_BD_MATERIALAUXPTY a
LEFT JOIN T_BD_FLEXAUXPROPERTY f ON f.FID=a.FAUXPROPERTYID
LEFT JOIN T_BD_FLEXAUXPROPERTY_L l ON l.FID=f.FID AND l.FLOCALEID=2052
WHERE a.FMATERIALID=867383 ORDER BY a.FAUXPROPERTYID;

-- 单料仅启用
SELECT a.FAUXPROPERTYID,f.FFLEXNUMBER,l.FNAME FROM T_BD_MATERIALAUXPTY a
JOIN T_BD_FLEXAUXPROPERTY f ON f.FID=a.FAUXPROPERTYID
JOIN T_BD_FLEXAUXPROPERTY_L l ON l.FID=f.FID AND l.FLOCALEID=2052
WHERE a.FMATERIALID=867383 AND a.FISENABLE='1';

-- 分组 10202 统计（375 全有 8 行，启用分布）
SELECT m.FNUMBER, COUNT(a.FENTRYID) AS AUXCNT
FROM T_BD_MATERIAL m LEFT JOIN T_BD_MATERIALAUXPTY a ON a.FMATERIALID=m.FMATERIALID
WHERE m.FMATERIALGROUP=117745 GROUP BY m.FNUMBER;

-- 分组内哪些维度被启用过
SELECT f.FFLEXNUMBER,l.FNAME,COUNT(*) cnt
FROM T_BD_MATERIAL m JOIN T_BD_MATERIALAUXPTY a ON a.FMATERIALID=m.FMATERIALID
JOIN T_BD_FLEXAUXPROPERTY f ON f.FID=a.FAUXPROPERTYID
JOIN T_BD_FLEXAUXPROPERTY_L l ON l.FID=f.FID AND l.FLOCALEID=2052
WHERE m.FMATERIALGROUP=117745 AND a.FISENABLE='1'
GROUP BY f.FFLEXNUMBER,l.FNAME;

-- 某属性（印字=100017）的值池与命中物料
SELECT DISTINCT m.FNUMBER, ml.FNAME, m.FFORBIDSTATUS, e.FAUXPTYNUMBER, l.FAUXPTYNAME
FROM T_BD_AUXPTYVALUE v
JOIN T_BD_AUXPTYVALUEENTITY e ON e.FAUXPTYVALUEID = v.FAUXPTYVALUEID
LEFT JOIN T_BD_AUXPTYVALUEENTITY_L l ON l.FENTRYID = e.FENTRYID AND l.FLOCALEID = 2052
JOIN T_BD_MATERIAL m ON m.FMATERIALID = v.FMATERIALID
LEFT JOIN T_BD_MATERIAL_L ml ON ml.FMATERIALID = m.FMATERIALID AND ml.FLOCALEID = 2052
WHERE v.FMATERIALAUXPROPERTYID = 100017;   -- 这里是属性FID，不是 T_BD_MATERIALAUXPTY.FENTRYID

-- 值分布：某个印字值被多少物料用到
SELECT e.FAUXPTYNUMBER, l.FAUXPTYNAME, COUNT(DISTINCT v.FMATERIALID) AS matcnt
FROM T_BD_AUXPTYVALUE v
JOIN T_BD_AUXPTYVALUEENTITY e ON e.FAUXPTYVALUEID = v.FAUXPTYVALUEID
LEFT JOIN T_BD_AUXPTYVALUEENTITY_L l ON l.FENTRYID = e.FENTRYID AND l.FLOCALEID = 2052
WHERE v.FMATERIALAUXPROPERTYID = 100017
GROUP BY e.FAUXPTYNUMBER, l.FAUXPTYNAME ORDER BY matcnt DESC;
```

## 坑位
- FISENABLE='1' 即校验单据必须填辅助属性值，FISMUSTINPUT='0' 仍会拦单据提交；勿以 FISMUSTINPUT 判断是否可空。
- T_BD_MATERIAL 本身无 FNAME/FSPECIFICATION，查显示名需 JOIN T_BD_MATERIAL_L (FLOCALEID=2052)。
- 辅助属性是分组级约定，单改一料会破坏同组 375 一致性，批量改需用户明确授权。
- `T_BD_AUXPTYVALUE.FMATERIALAUXPROPERTYID` 是**属性 FID**（印字=`100017`），不是 `T_BD_MATERIALAUXPTY.FENTRYID`；拿它去 join `FENTRYID` 会静默返回 0 行，看起来像“这个属性根本没有值”。
- `_L` 表的值显示名列是 `FAUXPTYNAME`（不是 `FNAME`）；值编码列是 `FAUXPTYNUMBER`（历史数据里可能是 `01`、`FZ00000131`、`B-15` 这类内部号），不要拿编码当业务含义。
- 启用维度 ≠ 有值：印字维度本账套启用 2580 条物料，值池只有 477 条且含“留空不填/白板/指定丝印”占位值，不能凭值池判断“哪些料有印字”。
- 全库查“某属性的值池”时不要用 `FMATERIALID` 反 join 属性表：一个物料对同一属性只应有 1 行值池单（`T_BD_AUXPTYVALUE` 按 `FMATERIALID + FMATERIALAUXPROPERTYID`），出现多行说明建过多次，取证时按 `FAUXPTYVALUEID` 分别列出。

## 单据侧处理
- 已报“生产补料单明细第N行物料N102020002的辅助属性维度…”时，在单据明细行点“辅助属性”列补选芯片尺寸与芯片数量值后重新提交；或在物料侧全组关闭后再重提。

## 印字 / 丝印查询（两套口径，必须两路都查）

业务说的“印字”（丝印 / 打标）在本账套有两个落点，回答时必须分开列命中数并说明另一路为 0 的原因：

1. **辅助属性 `FF100017 印字` 的值池**：按上面 SQL 用 `FMATERIALAUXPROPERTYID = 100017` 查。实测值形态是成品丝印码（`T4`、`JS`、`A1sHB`、`指定丝印`、`留空不填`、`白板`、`.712`）。这类维度实际用在客供晶圆/外购件上，2026 年生产订单里这些料 0 条。
2. **`FName` 末尾的印字后缀**：直插与外购件把印字写进名称，如 `NDD0510001 1N4148 BP`、`NDD0510002 1N4148 TB`、`NDZ0510019 BZX55C12V BP`、`DB3 BP 红管`、`1N4007  BP  (0.55*58)`。查法 `ml.FNAME LIKE '% BP%'`（注意可能双空格）；同一型号更换印字即新料号，换代号后旧印字料通常停用、旧编码 `FFORBIDSTATUS='B'`。

顺带一次查全“这个印字的料还在不在用”，比只看料号状态有用：

```sql
-- 生产订单：T_PRD_MOENTRY.FMATERIALID + T_PRD_MO.FDATE（该族为 0 条也照实报告）
-- 采购入库：T_STK_INSTOCKENTRY.FREALQTY + T_STK_INSTOCK.FDATE
-- 销售出库：T_SAL_OUTSTOCKENTRY.FREALQTY + T_SAL_OUTSTOCK.FDATE（注意不是 FQTY）
-- 现存量：  T_STK_INVENTORY.FQTY（该表无 FDATE）
```

结论口径：先给“有没有生产”一句话结论，再给最近一笔采购入库/销售出库的单号、日期、数量，最后才列料号清单。
