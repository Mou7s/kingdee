# 10501 铜框架建料（2026-09-17 PDFN3X3 双/单基岛实证）

## 一、分组与模板

`1050 铜/铁镍/镍钯金框架` 按材质分：`10501 铜框架`、`10502 铁镍框架`、`10503 镍钯金框架`。铜框架走 `10501`，实测统一模板（样板 `N105010030` / `N105010027` / `N105010029`）：

| 字段 | 值 |
|---|---|
| 类别 / ERP / 单位 | `CHLB01_SYS` / `1` / `K` |
| 购·存·销·产·委外 | 是·是·否·否·否 |
| 批号 | 是 + 规则 `PHBM004` |
| 默认仓 / 仓位 | `CTK01` / `100002` |
| 领料仓 / 仓位 | `CTK01` / `100002` |
| 其余 | 超短收 0/0、计划策略1 / EOQ1 / `ZZCL001_SYS`、税种 `WLDSFL01_SYS` + 税率 `SL02_SYS`、kg / m |

编号段 `N105010xxx`，当前最大 `N105010032`。

## 二、名称命名风格（同组现役）

按“基岛结构 + 镀银方式”命名，不把型号整串当名称：

| 名称 | 规格例 |
|---|---|
| `双基岛框架（全镀银）` | `0.65PDFN3.3X3.3-08B/Cu/48*74-48*74` |
| `单基岛铜框架LT （全镀银）` | `0.65PDFN3.3X3.3-08/Cw/101*74全镀` |
| `双基岛框架（条镀银）` | `PDFN5*6-8L(12R)(150*75)(150*75)`；`0.65PDFN3.3X3.3-08B/CU-A 局镀80U` |
| `单基岛框架（条镀银）` | `0.65PDFN3.3X3.3-08B/CU-B 局镀80U` |
| `铜镀银框架` / `铜镀银框架（片装）` / `铜镀银框架（卷装）` | 老料通用写法（SOT/TO-252/SOD 类） |

**规格照供应商送货单原文全写**（含 `局镀80U` 这类镀层说明），不截断；用户已确认。

## 三、同名不同规格是常态，但要报风险

`双基岛框架（条镀银）` 同时存在于 `PDFN5*6-8L`（`N105010030`）和 `PDFN3X3`（`N105010031`）。同组同名多料是账套惯例（如“铜镀银框架”有 20+ 条），建料时不拦；但**同名不同封装会让领料/采购看错**，建完后要主动提醒用户，必要时可加封装后缀区分（如 `双基岛框架（条镀银）PDFN3X3`）。

## 四、送货单只取物料信息

框架送货单上的 `数量 56K`、`50条（样品）`、`成品库:徐德琴`、开单日期、供应商电话/邮编都是业务数据，不写进物料主数据；只取“型号/规格”和“结构描述（双基岛/单基岛、条镀银/全镀银）”。

## 五、10502 铁镍框架（同构模板，名称更简单；2026-09-18 实证）

`1050` 按材质分 `10501 铜框架` / `10502 铁镍框架` / `10503 镍钯金框架`（10503 未实测）。铁镍归 **10502**，不要因为都叫「框架」塞进 10501。

实测 `N105020001~006` 与 10501 模板**逐字段一致**：`CHLB01_SYS / ERP1 / K / 购是·存是·销否·产否·资产否·委外否 / 批号是 + PHBM004 / 默认仓 CTK01 + 仓位 100002 / 领料仓同 / 超短收 0/0 / 计划策略1 + EOQ1 / 税种 WLDSFL01_SYS + 税率 SL02_SYS`；新料 `N105020007` 建后与样板 diff 只差编码/规格。编号段 `N10502xxxx`（当时最大 `N105020006`）。

名称现役一律只写「铁镍框架」（12 条全如此），不细分片装/卷装——与铜镀银组的 `铜镀银框架（片装）/（卷装）` 不同，别把铜组的名称模板搬过来。规格照用户/送货单原文全写（如 `SOT-23-3L(27R)(32x36)-A(Ni)`）；同封装历史写法可能用全角 `×`（铜框架 `SOT-23-3L(27R)(32×36) *0.127`），按原文写入后主动提醒用户可统一，不擅自改写，也不替用户补 `0.127` 这类板厚。

建料用 `scripts/tools/create_leadframe_material.js`（默认 dry-run、编码与名称+规格预检、Save→Submit→Audit→独立 View 回查），10501/10502 通用，跨组只改 `--group`。

## 六、厂码与「一点银」写法（2026-09-18 单基岛铜框架一点银YH 实证）

- 名称里的 `LT` / `KQ` / `YH` 是**供应商/厂码**，同结构不同厂各建一条是账套惯例；用户说“后面带 YH 的”就是按「单基岛铜框架一点银YH」写 `FName`。
- `一点银` = `1Ag`，两种写法在账套并存（`铜镀银框架KQ  (1Ag)`、`铜框架LT （1Ag）`）；用户口述中文“一点银”时照原话写进名称，不擅自换算成 `1Ag`。
- 规格照送货单原文全写，连字符/星号写法**不统一也不替用户统一**（`0.65PDFN3.3X3.3-08A/Cw/101*67` vs `0.65PDFN-3.3X3.3-08A/CU/101X67`）。
- **建前必查“近规格料”的实际使用量再请用户拍板**：`N105010026 铜框架LT（1Ag）` 与新料规格核心段几乎相同且高频在用（现存量 7862、BOM 子项 62 张、生产领料 3394 行、PPBOM 3499 行、PO 10 行），本次报出后用户确认“另一颗、要带 YH 的”，遂建 `N105010033`（编号段 `N105010xxx`，当时最大 `N105010032`）。建完要主动提醒：领料/采购在两条近似料之间容易选错。
- **送货单型号行 ↔ 料号对照（2026-09-16 送货单）**：`0.65PDFN3.3X3.3-08B/CU-A 局镀80U` = `双基岛框架（条镀银）`（`N105010031`）、`CU-B` = `单基岛框架（条镀银）`（`N105010032`）；单上只有型号/数量/备注（`56K`、`50条（样品）`、成品库/开单日期）时，只用型号去比对名称与规格。
- **追加厂码走改名，不新建**：用户说“这两款已经建过的，后面也加一个 YH”时，按 `原名 + YH` 原样拼接（不加空格）走 `UnAudit(C→D) → Save{FMATERIALID, FName} → Submit → Audit`，**规格/分组/类别/仓库一律不动**；改完双通道回查名称与 `C` 状态，并逐项比对非目标字段未变（2026-09-18 两条实测，改前两条引用面均为 0：无库存/BOM/PPBOM/领料/单据）。
