# 物料规格批量改名（封装段替换，2026-09-04 实战）

场景：封测规格截图给出一批“成品型号 + 封装形式”，要把 K3 成品料号规格的第一段封装
（如 `PDFN3X3`→`PDFN3030`/`PDFN3333`/`PDFN3.3*3.3-8`，`PDFN5X6`→`PDFN5060`/`PDFN5*6-8`）原样替换。

## 外部物料编码查不到

截图上的 `201603-xxxxx` 物料编码在 `BD_MATERIAL` 的 `FNumber` / `FName` / `FSpecification`
三字段都查不到（8 个编码实测全空）——它是外部编码。定位 K3 料号一律按**成品型号**
`FName like '%型号%'`，不要按外部编码搜。

## 同型号多料并存

同一型号可能有多条料（如 `SEM30GN60D3` 同时有 `NBM0750008` 无后缀版和
`NBM0760129 单芯`版）。改封装时两条都要改以保持一致。改名前精确查
`FName='目标名'` 确认无精确重名——带/不带 `单芯` 后缀算不同名，不冲突。

## 只换第一段，其余不动

新规格 = 新封装段 + 原规格剩余段落原文。空格、截断写法（如 `SEM 30P60`、`SEM 40GN45`）
一律保留，不要“顺手修正”。型号字母纠错（如 `GH→GN`）只在用户明确指出的那条做。

## 批量脚本模式

`jobs = [[料号, 旧规格原文, 新规格], ...]`，逐条守卫，单条 SKIP/ERROR 只记日志、继续下一条
（各料相互独立；失败不重跑全批，只补失败条）：

1. `executeBillQuery` 读当前：规格必须精确等于旧规格（不符则 SKIP 并打印实际值），状态必须 `C`。
2. 目标规格检索：`FSpecification='新规格'` 命中仅作提示；规格允许相同（2026-10-16 用户纠正），不得据此 SKIP。结合型号、名称及业务事实识别是否同物重复，现行规则见 `material-master-data-edits.md`。
3. 取 `FMATERIALID` → `UnAudit` → `saveBill("BD_MATERIAL", {FMATERIALID, FSpecification}, ["FSpecification"], ...)`
   → `Submit` → `Audit` → `executeBillQuery` 回查新规格 + `C` + `ForbidStatus`。
4. 中断恢复：先查状态；`B`（已提交待审核）说明 Save 已落地，只需补 `Audit`，不要重跑全流程。

实证：`NBM0750049/0760129/0760147/0750054/0750057/0750067/0760185/0750069` 8 条一次跑通；
此前单条 `NBM0750066/065/183/007/066/005/008/010` 同模式。
