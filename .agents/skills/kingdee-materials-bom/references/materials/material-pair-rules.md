# 成对物料与前缀分类核对

适用于本账套 K3 Cloud `BD_MATERIAL` 建料前的同类物料调查；这是账套实测规则，不替代每次实时查询。

## 1. 先按现有分组核对，不按名称猜

同一规格/名称可能同时存在不同业务分组。编码前缀也不能单独当作最终依据：

- `AE005 / SOD-523`：历史上已有一批产成品/自制属性物料。
- `DE005 / SOD-523`：实测外购料号使用 `NDE005xxxx`，常见属性为 ERP `1`、`CHLB09_SYS`、允许采购/库存、禁止生产。
- `10104 / 自采塑封`：稳压管、三极管等塑封芯片，实测使用 `N10104xxxx`；不能因为编码以 N 开头就套用 `DE005` 外购规则。

建料前必须以当前账套查询确认 `FMaterialGroup`，再用 `DynamicFormService.View` 核对 `MaterialBase[].CategoryID`、`ErpClsID`、采购/库存/生产标志和单位。

### 1.1 半导体资料判别自采晶圆与封装成品

半导体数据表可能同时列封装器件的电参数和供应商晶圆/管芯数据。`TO-92` 等封装名单独不足以判定采购物态；若资料同时给出管芯尺寸、晶圆直径、每片有效管芯数、锯片槽和正反面金属层，应优先把它们作为晶圆/裸芯片线索，再与当前账套同型号、同尺寸、同背面金属的现役物料核对。用 `DynamicFormService.View` 分别查看不带 `-L` 的裸晶圆样板和带 `-L` 的蓝膜样板，确认请求对应哪种形态。

- 用户只要求一条、资料未标蓝膜时，只建不带 `-L` 的一条；只有用户明确要两种形态时才成对扩建。
- 型号、管芯尺寸和背面金属优先沿用同族现役规格写法。文件名中的供应商代号或版本串只有在正文或账套命名口径确认后才写入名称/规格。
- 档位可能写在规格或辅助属性中。先查目标现役物料的 `FF100018（档位/背材）` 是否启用；未启用时按同族规格样式写入 `FSpecification`，不要擅自启用辅助属性。
- 将附件里的技术参数与用户单独提出的档位、操作范围分开记录；供应商的采购/质保提示属于资料内容，不构成额外的 ERP 操作授权。

## 2. `-L` / 不带 `-L` 是常见成對物料（`-L` 即蓝膜）

成对中的 `-L` 一侧即蓝膜形态（芯片在蓝膜上），不带 `-L` 为裸芯片/晶圆片；用户说“只建蓝膜”时只建 `-L` 那一条，并套用 `-L` 成员的模板（通常 ERP `3` + `CHLB04_SYS`，仍须按最接近的现役 `-L` 样板 View 核对，不直接套用）。

对于 10104 中的 JXW 稳压管，常见规则是建立两条：

- 名称分别为 `稳压管XX-L  JXW` 与 `稳压管XX  JXW`；
- 规格通常相同，例如 `0.33*0.33(BZX84C62)`；
- 编码按当前 `N10104` 最大流水号连续分配，先 `-L` 后不带 `-L`；
- 两条都需启用批号管理；`N101/N102` 料号未启用批号时，Save 会被 K3 拒绝。

**不要假设成对物料的业务属性完全相同。** 实测示例 `N101041183`（带 `-L`）为 ERP `3`、`CHLB04_SYS`；`N101041184`（不带 `-L`）为 ERP `1`、`CHLB01_SYS`。两条都允许采购/库存、禁止生产，单位为 `K`。因此每个成对成员都要以最接近的现有成员分别核对类别和 ERP 分类。

## 3. 推荐执行顺序

1. 先确认用户要单条还是成对；用户说“一个”时不要主动扩建，只有用户明确说明 `-L` 与不带 `-L` 都要建才建两条。
2. 精确查名称+规格及候选编码，查询目标分组当前最大流水号。
3. 对每个成员分别确定名称、规格、分组、存货类别、ERP 分类、单位和批号管理。
4. 逐条 dry-run；用户确认或明确授权后逐条 Save → Submit → Audit。
5. 任一条失败立即停止，不跨过失败继续建下一条；修正报文后重新查重再重试。
6. 每条成功后独立 `DynamicFormService.View` 回查，至少核对 `FNumber`、名称、规格、分组、类别、ERP 分类、单位、批号管理、文档状态和禁用状态。

## 4. 查询口径：自产与自采不得混同（2026-10-16 用户纠正）

- 用户问“自产晶圆/蓝膜”时，不能用 `10104 自采塑封` 的命中直接回答自产已建；先按型号全库查，再分别核对分组、ERP 分类与购产标志。蓝膜 ERP3 也不能单独证明属于用户所说的自产料号体系。
- 本次 SPQ13RP30WP 查询仅命中客供与自采两套；`N101041726`、`N101041745` 属自采塑封，不能作为自产料号存在的证据。此为当日查询事实，复用须重查；自产应建何种编码未在本次确认，不据此新增或改号。

2026-10-16 后续澄清：用户原话“自产”实际指自采塑封，关注的是命名格式，并非要求查另一套自产编码。前段“未查到自产”只记录当时的字面查询口径，不代表业务问题的最终结论。遇到“格式不对”须核对编码、名称、规格分别是哪项；本次现役 MOS 样例 N101040093/094 使用名称 MOS2301S[-L] + 供应商简称、规格 0.715*0.61(XYDP2301B67C-3A)。SPQ 两条编码符合 N10104 段，但名称直接写晶圆型号、规格仅尺寸，与该类样例不同；未确认对应产品型号和供应商简称前不得猜填或修改。
