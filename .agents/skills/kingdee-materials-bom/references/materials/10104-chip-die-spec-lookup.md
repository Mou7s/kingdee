# 10104 自采塑封芯片：按规格查重与 B2 双芯规则

2026-09-03 `JSP14N40AX-150` 双芯建料实证。适用于 `10104 自采塑封` 组中 FName 为成品型号、芯片型号藏在规格括号里的芯片类物料。

## 1. 查重必须同时查名称和规格

- 这类物料的 `FName` 是成品型号 + 供应商后缀（如 `芯片BAT54   JJ`），芯片型号只写在 `FSpecification` 括号里（如 `0.35*0.35(JSP14N40AX-150 )`）。
- 只查 `FName like '%JSP14%'` 会返回 0 条造成“无料”误判；必须同步查 `FSpecification like '%芯片型号%'`。
- 本次即靠规格查命中原单芯对 `N101041591（-L）/ N101041592`，名称查全空。
- 注意规格里的括号/空格细节：原条为半角括号 + `150` 后一个空格（`0.35*0.35(JSP14N40AX-150 )`），`View` 取 `Name/Specification` 原值核对后再定新规格字符串。
