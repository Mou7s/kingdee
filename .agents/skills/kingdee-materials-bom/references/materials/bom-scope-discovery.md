# 跨产品族 BOM 范围发现与分类检查

适用于把已验证的 PDFN3 BOM 用量规则扩展到 PDFN5 或其他封装族，先查范围，后决定是否写入。

## 查询步骤

1. `BD_MATERIAL` 查询父项：按用户确认的产品族规格模式（例如 `FSpecification like '%PDFN5%'`）和 `FName like '%单芯%'`，保留物料编码、名称、规格和状态。
2. 用父项物料编码查询 `ENG_BOM` 的**全部状态**；查询结果带分录时必须按 `FID` 去重。
3. 对每个唯一 `FID` 调用 `viewBill('ENG_BOM', fid)`，读取完整 `TreeEntity`。
4. 按子项名称精确分类：
   - 铝带恰好 1 条、铜线恰好 1 条；
   - 铜线至少 1 条且铝带为 0 条（纯铜线）；
   - 其他结构：无铜线、重复铝带/铜线或分录数量不符合。
5. 写入前输出分类数量、`FDocumentStatus` 分布、铜线当前用量分布和异常清单。

## 纯铜线的判定与写入边界

纯铜线 BOM 可能包含两条都叫“铜线”的分录，例如一条大用量和一条标准小用量。不得只输出或只依据小用量；逐条展示：

- `FEntryID`
- 子项物料编码
- 规格
- 当前 `FNUMERATOR`
- 单位

用户若只指定一个标准目标值，必须先确认目标作用于哪条分录；默认不要把大用量行合并、改写或当成标准线材用量。

## 状态边界

`C` 是已审核，`D` 是重新审核。两者必须分开统计；不能把 `D` BOM 无条件套入已验证的 `C` 批处理流程。每张写入前重新读取当前状态和目标前值，任一前值不符即停止扩散。

## 已验证的 PDFN5 探查口径

对 PDFN5 单芯父项做全状态实时查询时，结果需要同时报告：

- 铝带＋铜线各一根的数量及铜线用量分布；
- 纯铜线 BOM 的每条铜线分录；
- 不含铜线或结构不同的 BOM；
- `C` 与 `D` 的数量。

这份参考文件只记录可复用的探查方法，不授予任何批量写入授权；实际写入仍须用户明确确认目标分录和范围。
