# 物料分组选择：芯片、电脑和显示器

## 1. 芯片/晶圆体系

以当前本账套账套实测分组为准：

| 分组 | 名称 | 典型用途 |
|---|---|---|
| `10101` | 晶圆 | 自采/内部芯片体系的晶圆 |
| `10102` | 蓝膜 | 自采/内部芯片体系的蓝膜 |
| `10103` | 晶粒 | 自采/内部芯片体系的晶粒 |
| `10104` | 自采塑封 | 自采芯片/塑封前后相关芯片物料 |
| `102011` | N客供晶圆片 | 客供晶圆片，不带 `-L` |
| `102012` | N客供蓝膜片 | 客供蓝膜片，通常带 `-L` |

`102011` 与 `102012` 是两个物料分组，但当前账套的料号段共用 `N10201`，成对物料经常使用相邻编码；不能仅凭料号前缀判断分组，必须 View 回查 `MaterialGroup`。例如实测的 `N102012250 / N102012251` 分别属于 `102012 / 102011`。

对于 `102011/102012` 晶圆-蓝膜成对物料：

- 不带 `-L` → `102011 N客供晶圆片`；常见类别 `CHLB01_SYS`、ERP `1`、默认仓 `CTK04`。
- 带 `-L` → `102012 N客供蓝膜片`；常见类别 `CHLB04_SYS`、ERP `3`、默认仓 `CTK01`。
- 两条通常采购、库存、销售开启，生产关闭，批号管理开启，单位 `K`，计划策略 `1`。
- 规格通常只写芯片尺寸；若划片道会影响使用，写成类似 `1.645*1.265（含划片道）` 或 `0.695*0.770（含划片道70um）`。PAD 尺寸、PAD 金属厚度、胶水和合金线属于封装工艺资料，除非账套同类明确这样记录，否则不要放进物料规格。

## 2. 电脑/显示器按使用部门选组

当前有效物料提供了三类可比模板：

| 分组 | 名称 | 账套样例 | 真实属性/场景 |
|---|---|---|---|
| `30103` | 固晶 | `N301030268` 电脑主机、`N301030269` 显示器 | 车间/固晶现场设备；`CHLB10_SYS`、ERP `1`、单位 `Pcs`、默认仓 `CTK05`、采购库存开、销售生产关、批号开 |
| `GB001` | 电脑手机 | `NGB0010003` 组装电脑、`NGB0010001` 笔记本电脑 | 通用电脑/办公资产；`CHLB07_SYS`、ERP `10`、采购库存开、销售生产关、通常不启用批号 |
| `401` | 办公用品 | `N401000049` 笔记本电脑 | 行政办公用品；`CHLB08_SYS`、ERP `1`、默认仓 `CTK06`、采购库存开、销售生产关、通常不启用批号 |
| `30104` | 焊线 | `N301040047` ASM WB电脑主板 | 焊线机专用电脑部件，不适合通用电脑或显示器 |

因此：

1. 图片或采购订单只能提供品牌、型号、数量和价格，不能单独证明物料分组。
2. 先确认实际使用部门：车间/固晶现场优先查 `30103`；行政办公优先比较 `GB001` 与 `401`。
3. 若用户只说“电脑/显示器”而未说明用途，先列出候选分组并询问用途，不要因历史上有一条相似物料就自动照搬。
4. 采购数量不写进物料名称或规格；商店、价格、补贴和优惠券也不写进物料主数据。
5. 建料前应查精确重码、当前分组最新流水号，并用 `DynamicFormService.View` 读取代表物料的真实分类、ERP 属性、单位、仓库和批号标志。

## 3. 设备备件（301 系列）各组实测模板（2026-09-17 复核）

| 分组 | 类别/ERP | 单位 | 购·存·销·产 | 批号 | 默认仓 / 仓位 | 备注 |
|---|---|---|---|---|---|---|
| `30103 固晶` | `CHLB10_SYS` / 1 | `Pcs` | 是·是·否·否 | 否 | **`CTK05` / 0** | 278 条主流；少量批号是、少量 CTK06 |
| `30108 测试分选` | `CHLB10_SYS` / 1 | `Pcs` | 是·是·否·否 | 否 | **`CTK05` / 0** | 150 条主流；少数不设仓、2 条 CTK03 |
| `30109 其他` | `CHLB10_SYS` / 1 | `Pcs` | 是·是·否·否 | 否 | `CTK03` / 0 | 如 `N301090018 卷盘机气缸` |

共同：税种 `WLDSFL01_SYS` + 税率 `SL02_SYS`、计划策略 `1` / EOQ `1` / 政策 `ZZCL001_SYS`、领料仓 = 默认仓、超收短收 `0/0`、`FIsAsset/FIsSubContract=false`、采购/库存开、销售/生产关。

**不要把 30103/30108 的默认仓写成 `CTK03`**：“这几组统一 CTK03”的旧笔记只适用于 `30109`；30103/30108 实测都是 `CTK05`。

### 同名/同规格重复

- 同名不同规格直接建新的（30103/30108 同名多料是常态，如“开关电源”在 30103 有 6+ 条；`炉温测试仪` 与 `N301030184 测温仪` 是不同设备）。
- **同规格跨组仍按用户指定的工序建新料**：2026-09-17 `S-250-24` 已在 `30103`（`N301030080 AD8930-开关电源`），用户明确“卷盘机电源 测试分选的”，故在 `30108` 另建 `N301080159`。建前把同名/同规格现存料（含禁用旧料）列出来告知即可，不回头改旧料、也不强制复用。
- 相近型号要分开：`FU-34` 与 `N301080155 传感器 / FU-35TZ` 是不同型号，不合并。

### 号段与工具

30103 → `N301030xxx`；30108 → `N301080xxx`。建前用 `FNumber like 'N301030%'` + `OrderString:"FNumber DESC"` 取最大号，再精确预检候选占用。

`scripts/tools/create_material.js` **不写 `SubHeadEntity4`（计划策略）也不写 Model 顶层 `FCategoryID`**，对 301 备件会建出计划策略为空/默认的偏离料；这类备件用带完整 `PLAN`（计划策略1+EOQ1+ZZCL001_SYS）的专用报文更稳，或建后逐字段回查补齐。

## 4. 车间耗材/手套/防护用品选组（2026-10-16 实战纠偏）

车间防静电、洁净室作业耗材与日常劳保用品、设备备件的界限：

| 分组 | 名称 | 账套样板 | 适用范围与业务属性 |
|---|---|---|---|
| `404` | 生产辅料 | `N404000016` 无尘静电手套、`N404000020` 点胶手套(防静电)、`N404000056` 丁晴胶手套、`N404000096` 防静电手套(纤维 超细) | **洁净室/防静电车间作业消耗品**（防静电手套、静电衣、静电环、无尘布、美光胶、酒精等）；`CHLB14_SYS`、ERP `1`、默认仓 `CTK06`（杂品仓）、批号 `false`、购是·存是·销否·产否 |
| `402` | 劳保 | `N402000013` 手指套、`N402000069` PU手套、`N402000070` PU凃指手套、口罩、纸杯、拖把 | **通用劳保与日常消耗日用品**；主要供行政/后勤/通用保洁使用，默认仓 `CTK06` |
| `301xx` | 设备配件 | 30103/30108/30109 等（凸轮、轴承、电磁阀、吸嘴、滑块） | **仅限机器设备专用的机械与电气备品备件**，默认仓 `CTK05`。**手套、无尘耗材不得误入 301xx** |

**规则要点**：
1. **防静电/无尘专用耗材一律归 `404 生产辅料`**：涉及半导体封装测试洁净室的防静电手套、超细纤维手套、防静电手环、静电衣等，账套内同类现役物料均集中在 `404` 组，存货类别统一指定为 `CHLB14_SYS`，默认仓为 `CTK06`。
2. **误建纠错流程**：若误入 `301xx` 等不合适分组且未发生出入库等下游单据，经用户授权后按：实时核对 `FDocumentStatus` → `unAuditBill` 反审核 → `deleteBill` 物理删除并回查消失 → 在 `404` 取当前最大号顺延建立新料号（如 `N404000096`）并审核。
