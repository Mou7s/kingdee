# 五金/厂务类物料分组判定

## 建料工具回查注意（2026-10-29）

`create_equipment_part_material.js` 的指定样板名称从完整分组查询中定位，不能从近10条回退取另一个样板；计划策略 View 路径为 `MaterialPlan[0].PlanningStrategy`，不在 `MaterialProduce`。本次修正这两处日志/比对读取。工具仍会默认开启销售退货，旧厂务模板可能为 false；销售关闭时该差异不代表销售开启，不能宣称全部模板字段一致。证据：scripts/scratch/2026-10/probe-hardware-1029.js 与新料 N406000413/414、N409000120 的实时 View；编号及状态复用前重查。

## 适用场景

用户只给出“某零件/设备 + 五金”或类似泛分类，无法直接对应金蝶中的一个物料分组时使用。典型例子是增压泵、水泵、阀门、灯具和厂务维修配件。

## 判定步骤

1. **精确查重**：按名称、规格、编码分别查当前物料，区分已审核、草稿和禁用记录。
2. **扩展相似查询**：按功能词查询，如“增压泵/水泵/泵”，统计相似物料落在哪些分组；不要只搜用户给出的泛分类词“五金”。
3. **选代表物料做 View**：每个候选分组至少取一条现役、功能最接近的物料，读取完整实际值：
   - `MaterialGroup` 与名称；
   - `MaterialBase[].CategoryID`、`ErpClsID`；
   - 基本/库存单位；
   - 采购、库存、销售、生产标志；
   - 批号管理、默认仓库/领料仓、计划策略和制造策略；
   - 审核及禁用状态。
4. **以功能和用途定组**：实体厂务物料、设备资产、电器电具、生产辅料和维修费用可能分别有不同分组。用户说“五金”只说明业务口径，不能覆盖实际使用部门或同类模板证据。
5. **输出短方案再写入**：若分组、规格或料号由推断得到，先列候选和依据；先 dry-run，用户确认后再 `--apply`。不要因为“新建料号”就自动套用第一个相似分组。

## 已验证的对比案例

在本账套账套中查询“增压泵”时，曾同时得到：

- `N409000055`：`WZB-400A增压泵/智能自吸泵`，分组 `409 杂项/厂务`，规格含 `AC220V 400W`，类别 `CHLB08_SYS`，单位 `Pcs`，采购/库存/销售开启，生产/批号关闭。
- `N405020008`：`四分增压泵`，分组 `40502 电器电具类`，规格为空，类别同为 `CHLB08_SYS`，单位 `Pcs`，采购/库存开启但销售关闭，并有 `CTK06` 仓库。

因此“300W增压泵”不能仅凭“五金”直接决定分组；应结合是厂务自吸泵、电器电具，还是其他用途。若确认与第一条同为厂务实体泵，才可沿用 `409` 的模板；若用途不同，应重新按对应分组取模板。

## 本账套厂务/五金类分组与单位实测（2026-09-16）

三类口语“五金”实际落组不同，判定依据是**同用途现役样板**，不是笼统的“五金”：

| 物品 | 归属 | 依据样板 |
|------|------|----------|
| 雨布/遮阳类 | `409 杂项/厂务` | `N409000024 黑色遮阳布`(2*100米)、`N409000057 遮阳毯`、`N409000096 遮阳棉` |
| 型钢/角铁类 | `409 杂项/厂务` | `N409000032 30*30*3角铁*国标`、`N409000041 4*4角铁*国标` |
| 钻头/手工具 | `40501 五金工具类` | `N405010008 钻头 2.0`、`N405010015 手电钻钻头` |
| 螺丝等标准紧固件 | `405 五金/电具` | `N405000042 非标杯头螺丝 4*65`、`N405000105 杯头内六角螺丝 M3*8` |
| 信号转换/解码类电具 | `405 五金/电具` | `N405000021 光纤四路宽带网络转换器`（不是 401 办公用品，也不是 40501 工具类） |
| 电线/电缆/地线 | `406 电工材料` | `N406000331 2.5平方电线`、`N406000336 地线`、`N406000145 金环宇3*2.5+1*1.5国标电缆` |
| PVC 管件 | `406 电工材料` | `N406000352 6分弯头PVC`、`N406000033 4分弯头` |
| 铅笔/印刷品等办公耗材 | `401 办公用品` | `N401000071 铅笔` |

五组（`401`/`405`/`40501`/`406`/`409`）**除分组和单位外，模板完全一致**：`CHLB08_SYS / ERP1 外购 / 购是·存是·销否·产否 / 批号否 / 默认仓 CTK06 费用仓（仓位 0）/ 税率 SL02_SYS / 计划策略 1`，所以建料时只需定分组与单位。`405 五金/电具` 是紧固件与外购电具的落组，不等于 `40501 五金工具类`（工具）或 `40502 电器电具类`（灯具/风机/开关等建筑电气）。

单位口径（易错，必须按用途而非分组多数决定）：

- 电线、电缆、地线：**基本/库存单位都用 `m`**（如 `N406000331`、`N406000336` 均为 `m`）。
- 布类、管件、工具、文具：`Pcs`。
- 钢材按条：角铁 `N409000032/41` 为 基本单位 `Pcs` + **库存单位 `TIAO`（条）**；同类 C 型钢照此设 `TIAO`。
- 同组多数为 `Pcs` 不能覆盖用途惯例：`409` 组 85 条中库存单位为 `Pcs` 的 54 条，但钢材两条都是 `TIAO`，按“相同用途样板”取 `TIAO` 才对。

### `TIAO` / `tiao` 大小写撞名的写入坑（必须用 `FUnitId` 数值键）

账套同时存在两条“条”单位：`TIAO`(FUNITID `148159`，单位组 `10086`＝与 `Pcs` 同组，全局换算 `TIAO→Pcs` 1:1) 与 `tiao`(FUNITID `111841`，单位组 `10156`，换算目标 `10148`)。

- Save 传 `{FStoreUnitID:{FNumber:"TIAO"}}` 会按**大小写不敏感**匹配到 `tiao`；提交随即报一长串「库存单位/销售单位/采购单位/委外单位/生产单位/子项单位…与基本单位不存在换算关系」并把单卡在 `D`（`FStoreUnitID:{Id:148159}`、`FStoreUnitID_Id`、`{Number:"TIAO"}` 都被**静默忽略或不生效**，IsSuccess 仍为 true）。
- 唯一可用写法是 `{FStoreUnitID:{FUnitId:148159}}`（键名 `FUnitId`，值传数值单位内码），写入后 `View` 立即显示 `StoreUnit=TIAO(id=148159)`，再 `Submit`/`Audit` 通过。
- 排查口径：`SELECT FUNITID,FNUMBER,FUNITGROUPID FROM T_BD_UNIT WHERE FNUMBER LIKE '%iao%'` 找出撞名单位；`T_BD_UNITCONVERTRATE`（列 `FCURRENTUNITID/FDESTUNITID/FCONVERTNUMERATOR/FCONVERTDENOMINATOR`，`FMATERIALID=0` 为全局）确认哪个单位与基本单位同组且有 1:1 固定换算。
- 通用 `create_material.js` 传不了该键，遇到需要“条/卷/台”等非 Pcs 库存单位的组，应先建 Pcs、再按上述 `D → Save{FUnitId} → Submit → Audit` 修正，或直接用具名报文。

### 用 `create_equipment_part_material.js` 建 405/40501（2026-10-22 实证）

该工具的参数可覆盖分组/类别/仓库，适合这五组：`--group 405 --category CHLB08_SYS --stock CTK06 --unit Pcs`（默认 `CHLB10_SYS` 是 301 设备备件口径，必须显式覆盖）。已用此方式建成 `N405000134 杯头螺丝 5*40`、`N405000135 杯头螺丝 4*50`、`N405000136 解码器`、`N405010055 涂层合金钻 4.4`，四条均 C/A，分组/类别/单位/仓库/税率与同组样板一致。

**自动取号不要用于 `405`**：脚本的正则是 `^N${group}\d+$`，`group='405'` 会同时匹配到 `N40501xxxx` 段，可能算出 `N405010055` 这类跨段号。给 `--number` 显式指定，并在写入前按 `FNumber` 精确查占用。`405` 段当前为 `N405000xxx`（2026-10-22 水位 `N405000136`），`40501` 段为 `N405010xxx`（水位 `N405010055`），复用前重查。
