## 一、资料形态 → 建什么

| 资料 | 能定什么 | 建什么 |
|---|---|---|
| `{型号} 封装规格书 Eng{x}.pdf`（含 PKG / Device Name / Die Code / Die Size / Scribe Line） | 成品型号、封装、成品规格丝印写法 | 成品 1 条 |
| 生产流转单 / 委外订单（列：产品型号、封装形式、晶圆型号、晶圆批号、封装数量、Marking） | 型号 ↔ 晶圆型号对应关系 | 若晶圆型号未建档则补晶圆对 |
| `OEM-A####` 封装-装配示意图（金誉 JY-RE-001 版式，含客户代码/产品名称/芯片名称/封装形式/Die Size） | 成品型号、芯片(die)名称、Die Size | 成品 + 晶圆对 |

金誉（客户J半导体有限公司）：账套里**既是客户 `CTK000552` 又是供应商 `G036/G045`**；`SUB_SUBREQORDER` 委外订单里**查不到对它下的单**（现有委外供应商只有 GYS199/GYS080002/GYS080001/G050/G053/G026），所以 `OEM-A####` 图纸不是「本账套委外给金誉」的证据，物料口径按图纸/订单里的 产品名称/芯片名称 建。

## 三、规格写法

- 晶圆：Die Size `µm → mm` 保留 3 位；**文件里写了 Scribe Line 尺寸才加备注**，如 `4100um*2628um (include SL)` + `Scribe Line 60um` → `4.100*2.628(含划片道60um)`；同族若通行半角不带 um 的写法（SJS40 系 `3.379*1.730(含划片道)`）就跟同族。没有划片道资料时只写尺寸（金誉图纸只给 `0.396*0.390mm` → `0.396*0.390`）。
- 成品：封装/盘装/档位/丝印四段；Gross Die、模料、拉力推力、wafer 直径/厚度、标签尺寸、封装厂代码（除非同族通行）都不写进物料主数据。

## 四、编号与顺序

- 晶圆对共用 `N10201xxxx` 段（4 位流水），先 `FNumber like 'N10201%'` + `OrderString:"FNumber DESC"` 取真实水位（不能只按 `N102011%` 查，词序会误导）。
- **晶圆在前、`-L` 在后的写法（SJS40/CRMGL 族）与 `-L` 取小号的写法（APMG/APMT/PD620/WG 批）并存**，跟着同族走；`N10201` 段内连号分配。
- 成品段：`NBM013`、`NBI009` 等按 `FNumber DESC` 取最大号 + 逐个精确查占用。

## 五、蓝膜 BOM

父项 `-L` → 子项裸名，`1:1`、单位 `K`、分组 `0-lm`（`T_ENG_BOMGROUP.FID 274203`），编号自动 `{父项号}_V1.0`。Save → Submit → Audit → View 回查 `DocumentStatus=C`。
`executeBillQuery` 查 `ENG_BOM`：**没有 `FBillNo` 列**（报「元数据中标识为FBillNo的字段不存在」），编号字段是 `FNumber`；带分录字段要按 `FID` 去重。
**现行范围（2026-10-13 用户修正）**：新建晶圆片与蓝膜片完整对，或补齐缺少的一半后形成完整对，必须同时检查并补齐蓝膜 BOM，不再等待用户另行要求。按蓝膜父项 `FMaterialId.FNumber` 查询任意分组的已有 BOM，不能只按 BOM 编号前缀或同族习惯判缺失；已有正确且已审核、未禁用的 1:1 K BOM 就复用。没有则核对双方审核/禁用状态、单位和蓝膜「可为主产品」，建立 `0-lm` BOM 后用列表与 View 独立复查父子项、用量、单位、分组、审核及禁用状态。已有异常或操作失败时停止并报告未完成项，不扩展修改历史 BOM。老族过去未建 BOM 只作为历史事实，不构成此次成对建料的省略依据；此规则不授权全库历史补建，也不包含成品 BOM。

## 六、稳定脚本（2026-09-21 新增）

```bash
# 客供晶圆对（默认 dry-run，--apply 才写；内置编码/名称/规格预检 + Save→Submit→Audit→View 回查）
bun scripts/tools/create_wafer_material.js --number N102012312 --name "SJS40P6000PAA" \
    --spec "4.100*2.628(含划片道)" --group 102011 --stock CTK04 --bin 100015 [--apply]
# -L 蓝膜片：--group 102012 --stock CTK01 --bin 100001 --category CHLB04_SYS --erp 3 --sub-contract --main-prd

# 蓝膜 BOM（默认 dry-run；预检父项 C + 主产品 + 无同名 BOM）
bun scripts/tools/create_lm_bom.js --parent N102012313 --child N102012312 [--apply]

# 成品：用现成的 create_material_idm.js
bun scripts/tools/create_material_idm.js --number NBM0130249 --name "SJD020P04 单芯" \
    --spec "TO-252/2.5K盘/无/logo+SJD+020P04+客户周期码" --group BM013 --stock CTK11 --place 100051 \
    --erp 2 --category CHLB05_SYS --unit K [--apply]
```

`create_wafer_material.js` 只接受 `--group 102011|102012`，越界直接终止。仓位与批号规则随族不同：`--bin 100015`（晶圆片）/`--bin 100001`（-L）跟 SJS40 系；`--bin 0 --no-batch-rule` 跟 APMT/CRMTU/PD620 等新族（仓位留空 0、批号规则不传）。

**APMT 族晶圆对口径（2026-09-21 复验）**：走 `102011`/`102012`，**`-L` 取较小号**（`APMT24K0N03AV12M`：260=-L/261=裸名；`APMT38K0N03AV12M`：205=-L/206=裸名），与 SJS40 族相反；规格全角带 um（`1.982*1.381（含划片道60um）`）。同族里也有 `裸名` 在前的老对（`APMT9K50P10AP12M` 706=裸名/707=-L，2026-04、仓位 `100015/100001`+`PHBM004`），**按最近的几对定序**，拿不准就问。
